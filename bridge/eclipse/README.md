# Eclipse offline handoff prototype (not installed)

This directory is a **source integration patch**, not a compiled Eclipse plugin.

1. Copy `OpenRtosObservatoryHandler.java` into `plugins/io.github.niwantha33.zew.ui/src/io/github/niwantha33/zew/ui/` in zephyr-eclipse-workbench.
2. Merge the three `<extension>` sections from `plugin-extensions.xml` into that plugin's `plugin.xml` (do not nest `<plugin>`).
3. Run the existing PDE/Tycho build and installed-Eclipse smoke tests. **These have not been run by this package.**
4. Extract this package, set `RTOS_OBSERVATORY_HOME` to the extraction directory and restart Eclipse.
5. In Eclipse choose **Open RTOS Observatory (Offline Report)** and select the JSON generated by the standalone C++ CLI.

The handler writes a private temporary browser session containing the viewer and base64-encoded report. It never reads target memory or contacts OpenOCD/GDB. The active debug launch is only inspected for its launch mode in `handoff.txt` for future development.

## Future live-debug bridge

A live bridge requires a versioned IPC protocol and an implementation using DSF-GDB's owning session to accept *explicitly approved* suspended-state snapshot requests. Add a local authentication token, exact launch/project/ELF identities, target-state checks, read limits and timeout/cancellation. Never connect another GDB client to a single-client OpenOCD endpoint. No live bridge is implemented here.
